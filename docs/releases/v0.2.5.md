Windows 更新至补丁 revision 7，macOS 更新至补丁 revision 10。本次将此前仅在 main 中的更新正式打包发布。

### Windows

- 改善新版 Codex 的升级兼容性：校验官方签名和运行时版本，分别处理更新接口及外观变化；兼容性检查通过后才退出 App。
- 使用 App 原生更新按钮升级补丁副本，保留原有会话配置；修复重复更新提示和快捷方式指向旧副本的问题。
- 保留完整模型名（如 GPT-6 Astra）和实心 Fast 标识。Ultra 使用原生紫色；Fast 与模型名使用主题主文字色，深色主题为浅灰，浅色主题为深灰。
- 一键安装、卸载及稳定的 Codex Fast 启动入口；卸载保留 Codex 个人数据。

### macOS

- 改善 Sparkle 更新后的补丁交接与重开流程，修复更新组件签名不一致问题。
- 使用固定的 Storage helper，保留本机签名身份，并适配已验证的新模型控件布局。
- 保留原有 App 启动入口，提供一键安装和卸载脚本。

### 安装或升级

重新执行 [README 中的一键安装命令](https://github.com/infinityf4p/codex-fast-switch#一键安装)，即可更新补丁工具。Windows 也可下载下面的 **install.cmd** 后双击；卸载使用 **uninstall.cmd**。ZIP 内已包含运行依赖。

补丁工具升级与官方 App 更新分开：Windows 的官方包仍由 Microsoft Store 下载。Fast 请求发送 `service_tier: "priority"`，是否支持优先处理取决于模型和服务商。

Windows 26.911.61220（9647）已通过隔离副本的深浅主题与 Fast/Standard 请求验证。双平台安装包在对应系统构建并通过自动检查；实际 App 兼容范围及测试限制见 [测试记录](https://github.com/infinityf4p/codex-fast-switch/blob/v0.2.5/docs/tested-builds.md)。
